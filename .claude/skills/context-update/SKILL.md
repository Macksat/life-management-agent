# Context Update

オーナーの状況変化を [user_context.md](../../../data/llm_wiki/sources/memories/user_context.md) に反映する手順。

## 目的

user_context.md を最新に保ち、AI が常に正しい前提で動けるようにする。

## いつ実行するか

- 定期的な振り返り時。
- 重点テーマ・関心・仕事・スタックが変わったと分かったとき。
- オーナーから「これを覚えておいて」と文脈情報を渡されたとき。

## 手順

1. **既存文脈を確認** — まず LLMWiki の `people_self` `topics` `timelines` を見て、現在の文脈と衝突しないか確認する。
2. **変化を特定** — 何が変わったか(役割 / スタック / 関心 / 重点 / 価値観)。
3. **該当セクションを更新** — 既存記述を消さず、最新に書き換え or 追記。
4. **重点テーマを見直す** — 「現在の重点テーマ」を現実に合わせる(多すぎない)。
5. **変更履歴に記録** — 末尾の「変更履歴」に `YYYY-MM-DD: <要約>` を 1 行追加。
6. **最終更新日を更新** — 冒頭の「最終更新」を当日に。
7. **機微情報を除外** — 個人を特定する情報・機微情報は書かない([AGENTS.md](../../../AGENTS.md))。
8. **Wiki を再ビルドする** — `python3 scripts/build_llm_wiki.py` を実行する。

## チェックリスト

- [ ] 変更が具体的で事実ベースか
- [ ] 重点テーマが現実的な数に絞られているか
- [ ] 変更履歴と最終更新日を更新したか
- [ ] 機微情報を含めていないか
- [ ] 推測でなくオーナー確認済みの情報か(不確かなら確認する)

## 入力例 → 反映例

**入力:** 「最近は LangGraph より自作のエージェントフレームワークに興味が移ってる」

**反映:**
- 「現在の主な関心領域」を更新(自作エージェントフレームワークを追加 / 強調)。
- 変更履歴に `2026-XX-XX: 関心を自作エージェントFWへシフト` を追加。

## NG 例

- ❌ オーナー未確認の推測で価値観を書き換える
- ❌ 既存の重要文脈を削除する
- ❌ 重点テーマを 10 個に増やす
